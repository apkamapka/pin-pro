📍 Mapelo — mapa klientów dla mobilnych specjalistów
Uniwersalna aplikacja do zarządzania klientami na mapie z kolorowymi pinezkami opartymi o terminy wizyt. Stworzona dla hydraulików, elektryków, handlowców, weterynarz mobilnych, agentów ubezpieczeniowych i wszystkich, którzy pracują w terenie.
✨ Główne funkcje

Kolorowe piny na mapie — automatycznie zmieniają kolor w zależności od zbliżającego się terminu wizyty
Zarządzanie klientami — dane kontaktowe, notatki, zdjęcia, nagrania głosowe, oś czasu
Widok "Dziś" — lista klientów z dzisiejszymi wizytami
Widok "Okolica" — klienci posortowani wg odległości od Twojej lokalizacji GPS
Import klientów — z plików CSV/XLSX z automatycznym mapowaniem kolumn i geokodowaniem
Własne kategorie i pola — dopasuj aplikację do swojej branży
Tryb offline — dane przechowywane lokalnie, działa bez internetu
PWA + Android — instaluj jako aplikację na telefonie
PL / EN — pełna obsługa języka polskiego i angielskiego

🛠 Stack technologiczny

Vite + React + TypeScript
Tailwind CSS — stylowanie
Zustand — zarządzanie stanem
Radix UI / shadcn/ui — komponenty UI
Leaflet — mapa OpenStreetMap
Capacitor — natywna aplikacja Android
Vitest — testy jednostkowe
